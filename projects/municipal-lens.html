🏆 2nd Prize — Uppsala Kommun AI Hackathon

Municipal Lens: Turning Static Civic Data Into a Living Dashboard

A three-person team project applying human-computer interaction frameworks to redesign how Uppsala Kommun's public data reaches its residents — from research to a working React dashboard, in one sprint week.

Team Team of 3 — Uppsala University HCI cohort
Timeframe 1 Week Sprint
Data Source Kolada REST API (Swedish municipal data)
Tools React, Figma, Flourish

My role: as part of our three-person team, I contributed across the full pipeline — user research framing, Figma prototyping, and the React build — rather than owning one isolated piece. Below, "we" reflects team decisions; I've called out my own hands-on contributions where they were distinct.

// 01 . THE CHALLENGE

The Hackathon Brief

Uppsala Kommun's public records — school results, safety indicators, elderly care data — all live inside the nationwide Kolada database.

But the existing interface was hard to use: data was locked behind static, text-heavy tables, offered no way to compare across municipalities, and was available only in Swedish — a real barrier for non-native residents.

Municipal Lens is the name our team gave to the solution we designed on top of that data — not a rename of Kolada itself, but a resident-facing layer built to sit in front of it.

Core User Roadblocks

  • • Too data-heavy for non-experts
  • • Unclear comparisons between municipalities
  • • Language isolation (Swedish only)
  • • Low accessibility, no interactivity
// 02 . PROCESS

A Design Thinking Pipeline

Rather than jumping straight to code, our team ran the brief through a full Design Thinking loop — empathize, define, ideate, prototype, evaluate — to keep the build grounded in actual resident pain points.

1. Empathize Mapped resident frustrations with the current Kolada site.
2. Define Isolated visibility, accessibility & language as the core gaps.
3. Ideate Weighed a static dashboard vs. an API + BI toolkit approach.
4. Prototype Iterated from lo-fi wireframes to a high-fidelity Figma design.
5. Evaluate Checked contrast ratios and navigation flow before build.

♿ Accessibility, built in from the start

We designed a multilingual toggle (English / Svenska) directly into the interface so non-Swedish-speaking residents aren't locked out, and checked font–color contrast across every screen against WCAG guidance.

// 03 . PROTOTYPING

From Wireframe to Working Interface

Our first prototype was a low-fidelity Figma wireframe that established the core structure and a chatbot-guided user journey — deliberately simple, so the navigation logic could be tested before any visual polish went in.

Lo-Fi Prototype — Figma

Core layout and a language switcher (English/Svenska), built in from this earliest stage so multilingual access wasn't a later add-on.

The high-fidelity pass applied a clean, Swedish-minimalist visual language, unified typography and spacing, and — after a second ideation round — added a chatbot assistant to help residents find the metric they're actually looking for instead of hunting through menus.

High-Fi Prototype — Chatbot Assistant

Iteration 2: a chat panel offering quick shortcuts (Employment Rate, Education Stats, Population Data, Compare Cities) alongside free-text queries.

// 05 . CHALLENGES

What Made This Hard

Language

Kolada's underlying data — field names, categories — is Swedish-only, which we had to map into an English-first interface without losing meaning.

Signal vs. noise

Kolada exposes hundreds of metrics; deciding which ones actually matter to a resident, versus a municipal analyst, was a judgment call we had to make as a team.

Data gaps

Update frequency varies by metric, and some fields simply return no data for a given municipality — our UI needed to handle that gracefully rather than show a blank chart.

Result

At the close of the sprint, our team presented the working dashboard directly to Uppsala Kommun's jury — walking through the research that shaped it and the live system pulling real Kolada data. The project placed 2nd out of all participating teams.
